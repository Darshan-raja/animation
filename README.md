# Particle Animation for Portfolio

A beautiful particle animation that displays "Darshan D G" on page load, perfect for portfolio introductions!

## 🎬 Demo

Open `index.html` in your browser to see the animation in action.

## 📖 How to Use

See [INTEGRATION_GUIDE.md](INTEGRATION_GUIDE.md) for detailed integration instructions.

## ✨ Features

- Particle animation that forms text
- 3-second display with smooth transitions
- Auto-fade to reveal portfolio content
- Runs on every page load
- Fully responsive
- Easy to customize

## 🚀 Quick Integration

1. Add Three.js and GSAP CDN links to your HTML
2. Include `intro-animation.css` and `intro-animation.js`
3. Wrap your portfolio content in a `div` with `id="portfolio-content"`
4. Add the intro overlay structure

Full details in [INTEGRATION_GUIDE.md](INTEGRATION_GUIDE.md)!
